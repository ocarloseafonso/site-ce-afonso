# Documento 07 — Banco de Resultados e Casos
### Blog institucional — Carlos Eduardo Afonso | Volta Redonda

---

## 1. Objetivo deste documento

Este é o banco de situações reais que Carlos já viveu com clientes. É a base do que o Google chama de "experiência demonstrável" — a diferença entre um artigo genérico e um artigo escrito por quem realmente resolve esse problema no dia a dia.

**[OBRIGATÓRIO]** O agente só cita um caso quando ele se conecta genuinamente ao problema tratado no artigo (regra já definida no Documento 01, item 8). Nunca forçar.

**[OBRIGATÓRIO]** Respeitar sempre o nível de anonimização definido em cada ficha.

Carlos preenche este documento aos poucos, conforme for organizando os casos dos clientes atuais e passados.

---

## 2. Ficha-padrão de caso

```
=====================================================
ID:
NICHO: (clínica / salão / restaurante / oficina / outro)
SITUAÇÃO INICIAL: (o problema real identificado, sem detalhes que 
identifiquem o cliente se o nível de anonimização exigir)
O QUE FOI FEITO: (ação tomada, de forma resumida)
RESULTADO: (métrica ou fato concreto observável — número de contatos, 
posição no Google, visualizações, o que for verificável)
PODE CITAR QUANDO: (em quais temas/artigos esse caso se encaixa 
naturalmente — ex: artigos sobre categoria errada no Google, 
artigos sobre perfil incompleto)
NÍVEL DE ANONIMIZAÇÃO: (com nome / anonimizado sem nicho identificável / 
genérico, só o padrão do problema)
DATA DE REGISTRO:
=====================================================
```

## 4. Regras de uso

- **[OBRIGATÓRIO]** Nunca inventar ou estimar resultado. Se o dado real não estiver disponível, não citar número — falar do processo/problema de forma qualitativa.
- **[PADRÃO]** Preferir casos que ilustrem um padrão comum (algo que provavelmente se repete com outros negócios do mesmo tipo) a casos muito específicos e não generalizáveis.
- **[OBRIGATÓRIO]** Se o cliente não autorizou uso do nome ou de detalhes identificáveis, o nível de anonimização definido aqui é o limite — o agente não pode "deduzir" mais detalhes do que o permitido.
- **[PADRÃO]** Um mesmo caso pode ser citado em mais de um artigo, desde que sob ângulos diferentes e sem repetir a mesma frase/formulação — variar como o caso é apresentado.
